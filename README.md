# Apparel and Textiles Website

## 1. Project Introduction
This project is a responsive Apparel and Textiles website developed using HTML and CSS. The main objective is to create a user-friendly website that works properly on desktop, tablet, and mobile devices.

## 2. Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Google Chrome

## 3. HTML Structure
The website uses semantic HTML elements such as header, nav, main, section, and footer. It contains a hero section, collection section, product cards, benefits section, and footer.

## 4. CSS Implementation
CSS is used for styling the website. Flexbox is used to arrange product cards and benefit sections. Colors, padding, margins, borders, and shadows are used to improve the appearance.

## 5. Responsive Design
CSS media queries are used to adjust the layout for different screen sizes.
- Desktop: Product cards appear in a horizontal layout.
- Tablet: Product cards adjust to fit the available screen width.
- Mobile: Product cards appear vertically.

## 6. Testing Methods
The website was tested using Google Chrome Developer Tools. Different screen widths were used to check the responsive behavior on desktop, tablet, and mobile views.

## 7. Challenges and Solutions
One challenge was adjusting the product cards for different screen sizes. This was solved using CSS Flexbox, flex-wrap, and media queries. Navigation spacing and font sizes were also adjusted for smaller screens.

## 8. Conclusion
This project helped me understand responsive web design, CSS media queries, Flexbox, and website testing. The final website provides a consistent layout across different devices.
